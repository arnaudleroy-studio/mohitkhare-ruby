# MohitKhare

Developer utilities and token counting tools for Ruby by [Mohit Khare](https://mohitkhare.me).

[![Gem Version](https://badge.fury.io/rb/mohitkhare.svg)](https://rubygems.org/gems/mohitkhare)

## Install

```
gem install mohitkhare
```

Or add to your Gemfile:

```ruby
gem 'mohitkhare'
```

## Usage

```ruby
require 'mohitkhare'

puts MohitKhare::VERSION
puts MohitKhare::BASE_URL
```
