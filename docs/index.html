mohitkhare-ruby

Ruby developer utilities: LLM token counting, text slugification, and Markdown helpers.

About Mohit Khare

Developer utilities built by Mohit Khare, focused on AI engineering workflows. This Ruby package includes LLM token estimation, text processing, and Markdown conversion tools commonly needed when building applications on top of language models.

The token estimator is calibrated against the actual tokenizers used by GPT-4, Claude, and Gemini, providing fast approximate counts without requiring the full tokenizer libraries. Visit mohitkhare.me for more tools and articles on AI engineering.

# Installation

Ruby 3.0+ | Rails 6+ 
# Install the gem
gem install mohitkhare

# Or add to Gemfile
gem 'mohitkhare'

# Quick Start

require 'mohitkhare'

# Token estimation for LLM APIs
count = MohitKhare::Tokens.estimate(
  "Ruby is a dynamic, open source programming language.",
  model: :claude
)
puts "Tokens: #{count}"

# Smart truncation at token boundary
truncated = MohitKhare::Tokens.truncate(
  "Long text here...",
  max_tokens: 100,
  model: :gpt4
)

# Text utilities
slug = MohitKhare::Text.slugify("Hello World 2026!")
plain = MohitKhare::Markdown.strip("**bold** and _italic_")
puts "#{slug} | #{plain}"

# Features

  • Thread-safe, Rails-compatible, lazy enumeration
  • LLM token estimation
  • Text processing utilities
  • Markdown helpers
  • String manipulation

# API Reference

METHOD MohitKhare::Tokens.estimate(text, model:) -> Integer

Fast token estimation calibrated for GPT-4, Claude, and Gemini tokenizers.

METHOD MohitKhare::Tokens.truncate(text, max_tokens:, model:) -> String

Truncate text at the nearest clean token boundary, preserving readability.

METHOD MohitKhare::Text.slugify(input) -> String

Generate URL-safe slugs from any string with Unicode transliteration support.

METHOD MohitKhare::Markdown.to_html(md) -> String

Safe Markdown to HTML conversion with XSS protection and sanitized output.
